Nivel 1 · Fundamentos

¿Qué es la lógica booleana?

¿Qué es?

En programación, muchas veces necesitamos tomar decisiones según se cumplan o no determinadas condiciones. Por ejemplo, un sistema puede permitir el acceso a un usuario si su contraseña es correcta, o un estudiante puede aprobar si cumple ciertos requisitos.

Para resolver estas situaciones utilizamos la lógica booleana, que trabaja con dos valores:

  • True: representa verdadero.
  • False: representa falso.

En Python, estos valores pertenecen al tipo de dato bool.

# Valores booleanos en Python
es_mayor_de_edad = True
tiene_licencia = False

print(es_mayor_de_edad)
print(tiene_licencia)
Salida esperada True
False

Los operadores lógicos principales que estudiaremos son:

  • and (AND): verdadero cuando ambas condiciones son verdaderas.
  • or (OR): verdadero cuando al menos una condición es verdadera.
  • not (NOT): invierte el valor lógico; transforma verdadero en falso y falso en verdadero.
Analogía

Piensa en un semáforo: verde puede ser True y rojo False. Si cruzas solo cuando está verde, estás usando una condición booleana.

Recomendación

Antes de ejecutar un programa, identifica los valores de cada variable y determina el resultado esperado. Esta práctica ayuda a desarrollar el razonamiento lógico y a detectar errores en el código.

Nivel 2 · Comprensión

Tablas de verdad y operadores

¿Qué son las tablas de verdad?

Una tabla de verdad es una representación que muestra todos los posibles valores de entrada de una operación lógica y el resultado que se obtiene en cada caso.

Por ejemplo, si tenemos dos condiciones, A y B, cada una puede ser verdadera o falsa. Por tanto, existen cuatro combinaciones posibles:

Combinaciones posibles de dos condiciones
AB
VerdaderoVerdadero
VerdaderoFalso
FalsoVerdadero
FalsoFalso

Las tablas de verdad nos ayudan a comprender cómo funcionan los operadores lógicos antes de utilizarlos en un programa. En los ejemplos siguientes usaremos True y False, que son las representaciones de verdadero y falso en Python.

and Operador AND

El operador and devuelve True únicamente cuando las dos condiciones son verdaderas. Si al menos una condición es falsa, el resultado es False.

Tabla de verdad de AND
ABA and B
TrueTrueTrue
TrueFalseFalse
FalseTrueFalse
FalseFalseFalse
Ejemplo en Python

Imaginemos que un estudiante necesita aprobar dos evaluaciones para superar una asignatura.

aprobo_teoria = True
aprobo_practica = True
resultado = aprobo_teoria and aprobo_practica
print(resultado)
Salida esperada True

Explicación: el estudiante aprobó tanto la teoría como la práctica, por lo que ambas condiciones son verdaderas.

Si cambiamos la segunda variable:

aprobo_teoria = True
aprobo_practica = False
resultado = aprobo_teoria and aprobo_practica
print(resultado)
Salida esperada False

Esto ocurre porque una de las dos condiciones es falsa.

Ejemplo con una condición
edad = 20
tiene_entrada = True

if edad >= 18 and tiene_entrada:
    print("Puede ingresar")
else:
    print("No puede ingresar")
Salida esperada Puede ingresar

Para ingresar, la persona debe tener al menos 18 años y poseer una entrada.

Error frecuente

Confundir and con or. Recuerda: and es exigente, necesita que todas las condiciones se cumplan. Si una falla, todo falla.

Aplicación real

Un sistema de acceso a una plataforma escolar que exige usuario correcto y contraseña correcta usa el operador and.

or Operador OR

El operador or devuelve True cuando al menos una de las condiciones es verdadera. Solo devuelve False cuando todas las condiciones son falsas.

Tabla de verdad de OR
ABA or B
TrueTrueTrue
TrueFalseTrue
FalseTrueTrue
FalseFalseFalse
Ejemplo en Python

Imaginemos que un estudiante puede acceder a una actividad si tiene una beca o si ha pagado la inscripción. 

tiene_beca = False
pago_inscripcion = True
puede_participar = tiene_beca or pago_inscripcion
print(puede_participar)
Salida esperada True

Explicación: el estudiante no tiene beca, pero sí ha pagado la inscripción. Como una de las condiciones es verdadera, puede participar.

Ejemplo con una condición
es_fin_de_semana = True
es_feriado = False

if es_fin_de_semana or es_feriado:
    print("No hay clases")
else:
    print("Hay clases")
Salida esperada No hay clases

El programa muestra ese mensaje porque es fin de semana. No es necesario que ambas condiciones sean verdaderas.

Analogía

or es como una puerta con dos llaves: basta con tener una de las dos para abrirla.

Piensa y responde

¿Qué situaciones de tu vida permiten que “baste con una condición”? Por ejemplo, para obtener un descuento en una tienda basta con ser estudiante o ser adulto mayor. ¿Se te ocurren otros casos?

not Operador NOT

El operador not sirve para invertir un valor lógico. A diferencia de and y or, trabaja con una sola condición.

  • Si el valor es True, devuelve False.
  • Si el valor es False, devuelve True.
Tabla de verdad de NOT
Anot A
TrueFalse
FalseTrue
Ejemplo en Python
llueve = False
print(not llueve)
Salida esperada True

Explicación: como llueve vale False, el operador not invierte ese valor y devuelve True.

Error frecuente

Aplicar not a una comparación sin paréntesis. Aunque Python respeta la precedencia, es más claro escribir not (edad >= 18) que not edad >= 18.

Nivel 3 · Aplicación

Combinando operadores en problemas reales

Los operadores lógicos pueden combinarse para resolver problemas más completos.

Ejemplo 1. Verificar el acceso a una cuenta

Un usuario puede acceder si su nombre de usuario es correcto y su contraseña también es correcta.

usuario_correcto = True
contrasena_correcta = True

if usuario_correcto and contrasena_correcta:
    print("Acceso permitido")
else:
    print("Acceso denegado")
Salida Acceso permitido

Ejemplo 2. Aplicar un descuento

Una tienda ofrece un descuento si el cliente es estudiante o es una persona adulta mayor.

es_estudiante = False
es_adulto_mayor = True

if es_estudiante or es_adulto_mayor:
    print("Tiene derecho a un descuento")
else:
    print("No tiene derecho a un descuento")
Salida Tiene derecho a un descuento

Ejemplo 3. Validar una edad

Un sitio web permite registrarse a personas que tienen 18 años o más.

edad = 16

if not (edad >= 18):
    print("No puede registrarse")
else:
    print("Registro permitido")
Salida No puede registrarse

La expresión edad >= 18 es falsa porque la edad es 16. Al aplicar not, el resultado se vuelve verdadero.

Ejemplo 4. Comprobar requisitos de aprobación

Un estudiante aprueba si obtiene una nota igual o superior a 7 y tiene una asistencia igual o superior al 80 %.

nota = 8
asistencia = 90

if nota >= 7 and asistencia >= 80:
    print("Estudiante aprobado")
else:
    print("Estudiante no aprobado")
Salida Estudiante aprobado
Aplicación real

Estos patrones se usan en sistemas de matrícula, tiendas en línea, videojuegos (requisitos para subir de nivel) y aplicaciones móviles (permisos de acceso).

Nivel 4 · Análisis

Comparar operadores y evitar errores

Diferencias entre los operadores lógicos
OperadorSignificado¿Cuándo devuelve True?
andYCuando ambas condiciones son verdaderas.
orOCuando al menos una condición es verdadera.
notNOCuando la condición original es falsa.

Es importante recordar que los símbolos ∧, ∨ y ¬ se utilizan habitualmente en lógica formal para representar AND, OR y NOT, respectivamente. En Python se escriben con las palabras clave and, or y not.

Error frecuente

Pensar que or es exclusivo, como “uno u otro, pero no ambos”. En Python, or es inclusivo: si ambas condiciones son verdaderas, el resultado también es True.

Reto integrador

El guardián de la biblioteca

En tu colegio han decidido automatizar el préstamo de libros de la biblioteca. Te han contratado como programador junior para diseñar la lógica de decisión. El sistema debe evaluar si un estudiante puede llevarse un libro a casa.

Contexto

La biblioteca tiene tres reglas principales:

  • Un estudiante puede pedir un libro si está inscrito en la biblioteca y no tiene libros pendientes de devolución.
  • También puede pedir si pertenece al club de lectura o si cuenta con una autorización especial del docente.
  • Nadie puede pedir libros si su carnet está suspendido, sin importar las otras condiciones.

¿Qué debes lograr?

  • Escribir una función en Python llamada puede_pedir_libro que reciba las variables necesarias y devuelva True o False.
  • Utilizar correctamente los operadores and, or y not.
  • Probar la función con al menos cuatro combinaciones distintas de valores (casos de prueba).
  • Explicar con tus palabras por qué elegiste esa combinación de operadores.
  • Entregar el código y una breve justificación escrita.

Criterios de éxito

  • Comprensión: la lógica refleja correctamente las reglas de la biblioteca.
  • Aplicación: se usan and, or y not de forma adecuada.
  • Funcionalidad: la función devuelve los resultados esperados en todos los casos de prueba.
  • Creatividad: incluyes casos de prueba interesantes y bien documentados.
  • Calidad técnica: el código es legible, está indentado y usa nombres claros.
  • Argumentación: explicas tus decisiones y justificas la elección de operadores.
  • Buenas prácticas: comentas el código y evitas errores frecuentes.

Restricciones

  • No uses estructuras condicionales anidadas innecesariamente; busca una expresión lógica clara.
  • Tu función debe devolver un valor booleano, no imprimir directamente.
  • Incluye al menos un caso de prueba donde el carnet esté suspendido.
